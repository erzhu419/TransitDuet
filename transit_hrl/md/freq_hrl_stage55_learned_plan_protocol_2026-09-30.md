# Stage55 Protocol

Native six-arm validation: frozen, teacher, clone, sham, lower_ppo, joint_ppo; fixed periods 50/100 and deterministic/lower_sampled deployment. Retain the eight Stage42 warmup16 source roots; preflight has warmup2 and one root. Use fresh, disjoint forecast-fitting, teacher-label, critic-warmup, PPO-training and evaluation paths, paired across arms and periods.

Upper actions now execute an anchored quadratic Bernstein residual on Stage54's causal ridge forecast, using the existing plan mapper, four Gaussian actions and inherited maximum_subgoal_delta scale. Copy the source MLP trunk, initialize the residual mean head to zero and repeat each source entity std for its two coefficients. Lower is the original MLP with two zero-initialized planned-velocity columns. Critic input is base390 + plan_velocity2 + causal_clock2; retain inherited clock weights and initially zero velocity weights. No analytic feedback is used for learned-policy deployment. Promotion remains disabled to isolate plan/control learning.

Fit the unchanged forecaster once on 32 driver paths; collect eight deterministic native teacher-label paths per period. Clone and shuffled-label sham use identical datasets, 64 epochs, bounded-action tanh(mean) MSE, Adam lr=.0003, minibatch1024, fixed Gaussian std. Calibrate both critics for 16 iterations x eight native episodes with both actors frozen. Fork lower-only and joint PPO from this common state, then train 32 iterations x eight native episodes per arm and period with inherited PPO hyperparameters, native task-option credit and stochastic upper/lower actions. Use independent upper shuffle streams and identical lower shuffle streams; both initial batches and the first lower update must match exactly. No extra native verification rollout.

Evaluate all six fixed final policies on 16 paired paths per root, two periods and two deployment modes; no checkpoint selection, gain/feature/window tuning, seed extension or period/mode selection. Primary native deterministic return has 14 paired-root bootstrap contrasts, 65536 draws and Bonferroni14 intervals: teacher-frozen, clone-frozen, clone-sham, lower_ppo-clone, joint_ppo-lower_ppo, joint_ppo-frozen and joint_ppo-clone at both periods. Learnability requires clone beating frozen and sham at both periods; incremental joint gain requires joint beating frozen, clone and lower-only at both periods. These are distinct gates.

Full budget: 16128000 native steps and 13440 trace audits, including 153600 label, 2457600 critic-warmup, 9830400 PPO-training and 3686400 evaluation steps. Count actual BC/PPO actor/value optimizer steps, network changes, causal forecast/audit fits, Bernstein basis evaluations, plan decodes and upper/lower calls separately. Forecaster fitting is 256 generated driver paths, 281600 rows and zero native fitting steps. Preflight uses two paths, four BC epochs and two warmup/learning iterations: 22800 native steps and 76 audits. Tests, native preflight, full training and qualification run via scheduler on dynamic node001-node006, nine CPU / 12 GB per full task; pull compact JSON only.

## Limitations

This tests native residual HRL on a fixed learned forecaster with teacher initialization. Reused roots give conditional development evidence; fixed periods do not test promotion or identify frequency-separation utility. Equal evaluation calls are not equal FLOPs or total training budgets. BC loss and parameter changes establish learning execution, not reward improvement.
