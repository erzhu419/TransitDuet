# Matched Target Repair

Parent decision remains **PILOT_RECIPE_HOLD**. This is a bounded development
comparison, not a replacement confirmation protocol.

## Frozen Comparison

Keep all four original task/root groups and their controllers. On each root's
eight original branch-fitting paths, sample three uniform eligible bin starts
per path under the original history policy. Acquire eight paired conditional
futures/state, shared by all three targets:

- L: 50-step keep-minus-renew, with no later upper calls in the window.
- W: first 50 steps of wait-one-check-minus-renew, with adaptive continuation.
- G: complete-episode wait-one-check-minus-renew, with the same continuation.

Fit only the first four futures. Use the original 39 causal interaction features,
eight slope effective degrees of freedom, and a fixed 0.75 quantile of training
leave-one-path-out predictions for every target. No target-specific threshold
search, uncertainty reweighting, extra representation or controller training.
All rules are written before independent-future readouts or new-prefix access.

Reserve eight new development paths/root, `root+6000` through `root+6007`.
These are disjoint from all registered seed roles and resolved primary controller
training seeds. The just-revealed `root+5000` evaluation paths are not reused.
This is a current-pipeline reservation, not a global historical exposure audit.

## Readout

Report own-target training error on A, independent-future error on B, path-OOF
error on B, and new-prefix error on A/B/all. Also compare every head against G.
Keep repeat variance, corrected MSE and half-sign agreement; negative corrected
estimates remain visible. Do not correct training error using its shared noise.

Run all three learned rules and the three original frozen baselines on the eight
new complete episodes/root, reporting both four-path halves and paired path CIs.
Only two trained roots/task exist; these are descriptive conditional intervals,
not confirmatory cross-root evidence. Preserve the failed termination eligibility
and unknown interrupted lifecycle costs.

If G improves prediction but not episodes, target alignment alone is insufficient;
if W helps and G is noisy, retain the long-tail uncertainty rather than selecting
a favorable future block. No winner is automatically promoted or refitted here.

## Execution

Four one-CPU/2-GiB native prechecks must pass before four main jobs are submitted.
Use dynamic scheduler placement on node001-node006. Main jobs also require their
successful precheck artifact. Prechecks access only a training prefix; new held
prefixes remain untouched. Full banks and fitted rules stay on the server; only
compact public results are synchronized. Controllers are reused, so these costs
are marginal repair costs, not complete end-to-end lifecycle costs.

L/W/G use the same state features, which do not add remaining-episode time.
Labels follow the old policy after the intervention; complete-episode deployment
tests separately expose changes caused by repeatedly applying a new timing rule.
