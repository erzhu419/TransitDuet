# Journal Target

## Working target

The working target is *Transportation Research Part C: Emerging Technologies*
(TRC). Its scope fits the manuscript's transport-side contribution: real-time
bus operations and control, integration of artificial intelligence with
operational research, and explicit treatment of implementation and passenger
effects. The paper must therefore lead with the transit-control question and
use frequency-aware hierarchical RL as the method, rather than present a generic
RL architecture with a transit example.

## Working format

The generated package uses Elsevier's `elsarticle` class in 12-point preprint,
author-year mode, with a separate article-format Supplementary Material PDF. It
is an anonymous working manuscript with figures and bibliography flattened into
one directory. Author names, affiliations, CRediT roles, funding,
acknowledgements, and any required separate title page remain explicit
pre-submission metadata tasks. The submission portal and current TRC Guide for
Authors remain authoritative if they differ from this working format.
The generated `highlights.txt` contains four source bullets within Elsevier's
85-character limit; convert that source to the upload format required by the
portal at final submission.

## Scientific status

Journal formatting does not change the Protocol V6 decision. V8 provides a
registered short-training regularity result with passenger-journey no-harm. V9
does not confirm the registered long-training regularity magnitude. The current
