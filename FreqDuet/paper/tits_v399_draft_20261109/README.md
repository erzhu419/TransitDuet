2026-11-09。从 V352 论文稿独立复制更新，旧论文、算法、checkpoint 与实验结果不改。
默认仍是 K4/V326、314011/b8、预算保留下限 0.5；不是把 0.25 晋升为主策略。

joint 的证据仍不足。

| 读者问题 | 正文位置 | 证据与范围 |

历史内部对照降为辅助结果，不再靠较弱旧 learner 的改善充当主要上层优势。

## 术语

| 术语 | 本稿含义 |
| --- | --- |
| FreqDuet | 频率信息支持的时刻表—holding 协调架构 |
| manual joint | 同时启用既有计划规则和预算机制的强手工联调，不是 fixed 或 TransitDuet 的别名 |
| rho_B | holding 指令预算保留下限，不是车辆比例；同下限不意味着同实际 holding |
