## 构建与证据

运行 `bash build.sh`，再运行 `python3 verify.py`。PDF 位于 `output/pdf/main.pdf`。
`build_tables.py` 只格式化既有统计，不重新求均值、bootstrap 或调比较权重。
四张生成的主结果表含 37 个估计项，均映射到 `evidence_manifest.json` 的原 JSON 字段。
`evidence/` 仅复制六份本地已有小汇总，无新下载、权重或原始轨迹。

`python3 package.py` 生成离线论文源码包。它可重建主表和 PDF；不等于完整交通实验复现包。
完整实验仍需要 manifest 所列的冻结 runtime、输入数据和 supervisor 工件。
文献支持范围见 `literature_checks.md`；术语、论点和作者待决事项见 `terminology.md`。

已完成 10 页渲染检查、37 项表格证据校验和源码包独立解压重建。最终构建没有溢出、
未定义/重复引用或 BibTeX 告警；少量非致命 Underfull 排版提示未造成遮挡或缺字。
